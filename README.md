# cursuri-utm-md
UniShare este o platformă creată de studenți, pentru studenți. Aici poți învăța de la colegii mai mari sau îți poți transforma cunoștințele în venituri reale. Studenții cu experiență își publică propriile cursuri, iar bobocii le pot cumpăra pentru a învăța mai ușor, mai practic și mai rapid.
